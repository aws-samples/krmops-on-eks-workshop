# workshop-tf-baseline

Terraform stack that reproduces the **Module IV RDS WebStack** (from the KRM/kro on EKS workshop) — but managed by Terraform instead of `kubectl`. This is what Module 5 migrates from.

## What it deploys

**AWS resources**
- Amazon RDS for PostgreSQL (single-AZ, `db.t4g.micro`, workshop-sized)
- AWS Secrets Manager secret holding the RDS master credentials
- IAM role for the web app pod
- IAM policy granting `secretsmanager:GetSecretValue` on that one secret
- EKS Pod Identity Association binding the role to the pod's ServiceAccount

**Kubernetes resources** (deployed via the `kubernetes` provider)
- Namespace `webapp-rds`
- ServiceAccount `webapp-sa`
- `SecretProviderClass` (Secrets Store CSI driver) that mounts the RDS creds
- Deployment (nginx-based demo image) with the volume mount + env vars from the CSI-projected secret
- Service (ClusterIP)

## Prerequisites

- Terraform ≥ 1.6
- The workshop EKS cluster from Module I is already running
- Your kubeconfig context points at the workshop cluster
- IDE role has permissions to create RDS, IAM, Secrets Manager, EKS Pod Identity

## Deploy

```bash
cp terraform.tfvars.example terraform.tfvars   # edit if you want to override defaults
terraform init
terraform plan
terraform apply -auto-approve
```

Takes ~8–10 min (RDS provisioning is the long tail).

## Verify (this is Module 5 Step 3)

```bash
terraform state list
terraform output
kubectl get all -n webapp-rds
kubectl get secretproviderclass -n webapp-rds
```

## Destroy (after workshop)

```bash
terraform destroy -auto-approve
```

## Notes for facilitators

- **RDS deletion protection is OFF** to make workshop cleanup fast. Do not copy this pattern to production.
- The DB password is generated by `random_password` and written to Secrets Manager — never returned in Terraform state cleartext for reads, but the raw string is in state. Fine for a workshop; use `ephemeral` blocks in production.
- Backend defaults to local state. For multi-attendee workshops, switch `providers.tf` to an S3 backend keyed by `workshop_id`.
